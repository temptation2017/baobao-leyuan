# 🌙 宝宝的乐园

给 2 岁女儿做的互动式"数字游乐场"网页版（v2 完整版）。

**在线玩（GitHub Pages 持久地址）：https://temptation2017.github.io/baobao-leyuan/**

## 功能

- 🐶 **动物卡**：10 种小动物，点一点听叫声、看小知识（含 8 张 AI 插画）
- 🔍 **找一找**：听指令找出指定动物，答对得星星
- 📖 **听故事**：5 篇 2–3 岁睡前故事（31 段中文配音），讲完自然收尾
- 🎨 **涂色**：6 张图案，点选上色
- 🔢 **数一数**：1–5 点数小游戏，点着数、选答案
- ⭐ **星星奖励**：本地 localStorage 记录
- 🔒 **家长门**：加减法验证，单节 10/15/20 分钟可选，到点温柔收尾

## 设计原则

- 无广告、无内购、无自动播放、无账号
- 内容全部内置，不上传任何数据
- 单文件入口 `index.html` + `assets/` 静态资源，零构建、断网可跑（首次加载后）

## 本地预览

```bash
cd baobao-leyuan && python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```
